# DevOps Fundamentals Project

## 1. Project Overview
This project demonstrates basic DevOps practices using Ubuntu,
Git, GitHub, Apache, and Bash scripting.

## 2. Website
The project website is stored in index.html and is served
using the Apache web server.

## 3. Bash Scripts
The scripts directory contains health-check.sh.

## 4. Health Check Script
The health-check.sh script checks:
- Server hostname
- Server uptime
- Disk usage
- Memory usage
- Apache service status

## 5. Version Control
Git is used to track project changes, and GitHub hosts the
project repository.

## 6. Execution
Run the health-check script using:
./scripts/health-check.sh
